# Caio Kellermann Sabino - Interactive Professional CV

Repositório oficial contendo o currículo web interativo de alta performance de Caio Kellermann Sabino.

## 📂 Estrutura Padrão do Repositório (GitHub Best Practices)

```text
/
├── README.md       # Documentação principal e instruções do repositório
└── index.html      # Página web principal contendo o currículo bilíngue (PT/EN), alternador de tema Light/Dark e Assistente de IA para recrutadores
```

## 🚀 Como Hospedar no GitHub Pages

1. Crie um novo repositório público no seu GitHub (ex: `caiosabino-cv`).
2. Faça o upload dos arquivos `index.html` e `README.md` na **raiz** do repositório.
3. No seu repositório, vá em **Settings** > **Pages**.
4. Em **Build and deployment**, selecione a branch `main` (ou `master`) e a pasta `/ (root)` e clique em **Save**.
5. Em instantes, o GitHub fornecerá o link público para o seu portfólio profissional!
